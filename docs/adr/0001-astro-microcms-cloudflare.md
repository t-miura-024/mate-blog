# 自作の公開ブログを Astro + microCMS + Cloudflare で構築する

note や Instagram などの既存サービスに寄せず、公開ブログを自作する。理由は 2 つ。デザインと公開ルールを自分たちで完全にコントロールするため（広告やレイアウトを外部仕様に縛られない）、そしてコンテンツデータを自前で所有し、サービス終了に左右されず長期保存するため。構成の骨格は Astro + React + Tailwind CSS（フロント）、microCMS（コンテンツ管理）、Cloudflare（配信）。執筆者は非エンジニアの母親 1 人であり、執筆体験は microCMS の管理画面で完結させる。配信方式（静的 / SSR）や画像最適化などの詳細は後続の ADR で決定する。
